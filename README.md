## 🧠 Topics Covered

This repository spans a wide range of foundational to advanced Python topics:

* **Core & Control Flow:** Advanced loops, conditional structures, and pattern-printing logic.
* **Functions & Modules:** Lambda functions, decorators, generators, iterators, and custom modules.
* **Data Structures:** Advanced usage of lists, tuples, dictionaries, sets, and comprehension techniques.
* **File Handling:** Reading, writing, and managing various file formats (text, CSV, etc.).
* **Error & Exception Handling:** Using `try`, `except`, `else`, `finally`, and custom exceptions.
* **Object-Oriented Programming (OOP):** Classes, objects, inheritance, polymorphism, encapsulation, and abstraction.
* **Practice & Assignments:** Curated problem statements and practical implementations for real-world scenarios.
